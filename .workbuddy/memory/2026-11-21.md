# 2026-11-21

## 文件夹隐藏工具 v1（方案 A）实现

- 技术栈：Wails 3.0.0 + Go 1.27 + 原生 JS/Vite。模块名 `folderhide`，`main.go` 在根目录，后端代码集中在 `backend/`。
- 核心方案：给目录名追加 `..` 并加 `FILE_ATTRIBUTE_HIDDEN`；Win32 会剥掉普通路径末尾句点，导致资源管理器双击报“位置不可用”。恢复时反向改名并清除隐藏属性。
- 关键坑：Go 的 `filepath.Clean/Abs` 会把 `foo..` 规范化成 `foo`，必须先拆分末段再拼回，不能对整个路径 Clean。已实现 `canonicalPath`/`joinChildPath` 保留末段，并通过 `\\?\` + `MoveFileEx` 绕过 Win32 规范化。
- 功能：原生目录选择、含隐藏项的子目录枚举、隐藏/显示、隐藏清单（%AppData%\FolderHideTool\state.json）、日志事件 `folder-log`、系统与程序自身目录保护、重名冲突检测。
- 验证：`go test ./backend` 2 项通过（往返隐藏/恢复、重名冲突）；`go vet` 通过；`wails3 build` 成功，产物 `bin/my-folder-encryption.exe`（约 11MB）。
- 后续若做方案 C（保留名 CON/NUL），需复用同一 Win32 层并强制持久化原名，因为保留名改名后无法从磁盘反推原目录名。

## v1.1：三面板与方案 C

- 标签页改为 `方案A` / `方案C` / `关于`，日志区三个面板共用；窗口仍为 414×319。方案 C 下拉保留名由后端 `ReservedNames()` 动态填充，关于面板不显示密钥字面值。
- 方案 C：先把原名用 AES-256-GCM 加密（密钥由内置字符串经 SHA-256 派生，nonce 随机 12 字节）写入被隐藏文件夹内部的 `.DS_Store`（带 HIDDEN|SYSTEM 属性），再用 `\\?\` + `MoveFileEx` 改名为保留名并加隐藏属性；解密时反向读取元数据、校验重名、恢复并删除 `.DS_Store`。
- 新增文件：`backend/reserved.go`（纯 AES/元数据逻辑）、`backend/reserved_windows.go`（扩展路径文件读写与隐藏/恢复流程）、`backend/reserved_other.go`（非 Windows 桩）、`backend/reserved_test.go`、`backend/reserved_windows_test.go`。
- `backend/service.go` 新增 `EncryptReservedFolder`、`DecryptReservedFolder`、`ReservedNames`，Version 升为 1.1.0；主窗口标题同步为 v1.1。
- 验证：11 项 Go 测试全部通过（含方案 C 往返、多保留名、损坏元数据、重名冲突、非法名）；`go vet`、`wails3 build` 均通过；前端产物确认不含密钥字面值。
- 后续实测发现方案 C 在当前 Win11（build 26300）可被资源管理器通过 Shell PIDL 打开，普通 Win32 路径会解析成 NUL 设备；因此方案 C 不可靠，已在 v1.2 删除。

## v1.2：删除方案 C，改为方案 D（ACL 拒绝列目录）

- 标签改为 `方案A` / `方案D` / `关于`；方案 D 表单只有目标路径与加密/解密按钮，无保留名选择。
- 方案 D 原理：备份目录 DACL 为 SDDL，AES-256-GCM 加密写入目录内 `.DS_Store`，再追加仅针对当前用户 SID 的 `FILE_LIST_DIRECTORY` 拒绝 ACE 并设置隐藏属性；双击因无法列目录而失败。解密时先读元数据恢复 DACL，再清隐藏属性并删除 `.DS_Store`。
- 关键坑：`FILE_LIST_DIRECTORY` 与 `FILE_READ_DATA` 同为 0x1；拒绝后工具仍可读取 `.DS_Store`（只需 traverse），但无法写入/删除/改属性，因此必须先恢复 ACL 再清理元数据。`ACL.DACL()` 第二返回值是 defaulted 而非 present，不能据此判空。
- 新增文件：`backend/metadata.go`（AES 信封）、`backend/metadata_windows.go` / `metadata_other.go`（元数据文件读写）、`backend/scheme_d_windows.go` / `scheme_d_other.go`（ACL 备份/拒绝/恢复）。删除全部 `reserved*.go`。
- `backend/service.go` 改为 `EncryptFolderByACL` / `DecryptFolderByACL`，Version 1.2.0；`main.go` 标题 v1.2。
- 验证：9 项 Go 测试全部通过（AES 信封、ACL 往返、已存在元数据拒绝覆盖、损坏元数据不恢复、方案 A 原测试）；`go vet`、`wails3 build` 通过；全项目已无“方案C/保留名”残留。
