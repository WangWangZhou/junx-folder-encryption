## 修复单实例唤醒时窗口只到任务栏不置前
- 根因：`OnSecondInstanceLaunch` 运行在后台 goroutine（Wails single_instance.go 的 channel 消费者），虽用 InvokeSync 切主线程，但 `window.Show().Focus()` 底层的 `SetForegroundWindow` 受 Windows 前台锁定限制——无用户输入上下文的进程调用会被拒绝，窗口显示但不弹到最前；托盘点击因是真实用户输入故正常。
- 修复：新增 `windowfront_windows.go`（build tag windows）的 `bringWindowToFront()`：`window.Show()` → `w32.KeybdEvent(VK_MENU) + KEYEVENTF_KEYUP` 模拟 ALT 按下/释放解除前台锁定 → `BringWindowToTop` + `SetForegroundWindow` → `window.Focus()` 让 WebView2 拿到焦点；非 Windows 用 `windowfront_other.go` 退化为 `Show().Focus()`。
- `main.go` 的 `restoreAndShow()` 把 `window.Show().Focus()` 换成 `bringWindowToFront(window)`，托盘与单实例恢复共用；ALT 模拟在主线程执行（InvokeSync 保证）才有效。
- 依赖用 Wails 公开的 `github.com/wailsapp/wails/v3/pkg/w32`（KeybdEvent/BringWindowToTop/SetForegroundWindow 均已导出），无需新增 go.mod 依赖；`dispatchOnMainThread` 的 `isOnMainThread()` 保证嵌套 InvokeSync 不死锁。
- 验证全通过：`go test ./...`、`go vet ./...`、`go build`、`wails3 build`。README 功能/使用/项目结构同步更新。
